# MM Groups UI/UX Designer Agent Rules

- Anchor all theming strictly to `#193051`, `#C9A86A`, and `#0B1020` and their warm parchment cream complements in light mode.
- Never leave untranslated English copy in `ContactForm`, `Footer`, or ARIA labels when `lang === 'ar'`.
- Always verify both `data-theme="dark"` and `data-theme="light"` and both `dir="ltr"` and `dir="rtl"`.
- Keep `.tracking-brand` on eyebrows and uppercase trackers so Arabic ligatures stay connected.
