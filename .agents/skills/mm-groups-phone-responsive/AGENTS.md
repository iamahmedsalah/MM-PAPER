# MM Groups Phone Responsive Agent Rules

- Never rely on hover-only affordances to inspect the 6 3D paper cards on mobile devices; always provide tap toggle support.
- Never drop mobile input font-size below `16px` (`text-base sm:text-sm`).
- Always verify `320px` width in both `en` (LTR) and `ar` (RTL) so headings, stats strips, filter chips, and cards never clip or overflow horizontally.
- Keep `Lenis` disabled on coarse-pointer touch screens so native mobile scroll inertia stays crisp.
